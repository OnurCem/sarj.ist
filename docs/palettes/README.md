# Palette screenshots — September 7

These four images are actual 1536 × 1024 browser screenshots of the Astro prototype, captured with temporary CSS overrides. The original burgundy theme was restored afterward. No palette switcher was added.

- **01 Volt:** near-black #191D17, electric yellow #E3FF48, selected surface #F4F8D7. Button text/background contrast 15.18:1; secondary text on selected surface 5.27:1.
- **02 Vermilion:** charcoal header #2C2522, red-orange #C83220, porcelain #FFFDF9, selected surface #FFE8DF. White button text contrast 5.34:1; secondary text on selected surface 4.81:1.
- **03 Iris:** violet #5535C4, white panels, selected surface #F0EAFE. White button text contrast 7.80:1; secondary text on selected surface 4.68:1.
- **04 After Hours:** midnight #101A23, slate panels #18232D, cyan #64E3EE, pale text #EDF8FF. Button text/background contrast 10.93:1; secondary text on selected surface 6.44:1.

Ratios were calculated using sRGB relative luminance, with browser read-back of applied colors. Main body text exceeds 14:1 in all four. These are checks of the specified text/color pairs, not a full accessibility certification. Third-party raster-map labels and every interactive state have not been individually audited. The earlier SVG sheet's approximate contrast claims should not be relied on.

The same selected C logo, text, layout, map position, sample stations and detail card are used in all four screenshots. Dark-mode map tiles use a temporary CSS filter; a production dark map should use a designed map style. Light palette map styling is identical across captures.
